# Лабораторная работа №4: Автоматизированная инвентаризация и мониторинг рабочей станции

* **ФИО:** Агайдарова Дарина Муратовна
* **Вариант:** №1

## Содержимое проекта
* `inventory.py` — агент инвентаризации, формирующий паспорт системы в формате JSON.
* `monitor.py` — скрипт мониторинга ресурсов с записью в CSV-журнал.
* `passport_<hostname>.json` — сгенерированный технический паспорт.
* `monitor_log.csv` — лог-файл замера показателей.
